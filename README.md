# 社会学習サポート（ワーク中心）

中学1年の社会（アジア州・ヨーロッパ州・歴史）を学習するためのゲームです。学校ワークの内容を参考に作ったオリジナルの類題を使用しています。

## GitHub Pages で公開する

1. GitHubで新しいリポジトリを作成します（例：`shakai-study`）。
2. このフォルダにある `index.html` をリポジトリの**一番上の階層**にアップロードして、`Commit changes` を押します。
3. リポジトリの **Settings → Pages** で **Deploy from a branch** を選択し、ブランチを `main`、フォルダを `/ (root)` にして保存します。
4. 公開されたURL（通常 `https://<ユーザー名>.github.io/<リポジトリ名>/`）を開きます。

`index.html` は単体で動くよう作られているため、リポジトリにはこのファイルだけでも大丈夫です。

## 記録について

回答履歴・苦手問題などのデータは、各ブラウザ内のローカルストレージに保存します。GitHubには自動送信されず、スマホとPC間でも自動同期しません。ブラウザのサイトデータを消すと失われる可能性があります。利用者の個人情報は、公開リポジトリには記入しないでください。

## 編集・運用上の注意

GitHub Pages のURLは一般に誰でもアクセス可能です。校内資料、氏名、成績、秘密情報は公開しないでください。アプリ本体に外部サーバーは不要です。
