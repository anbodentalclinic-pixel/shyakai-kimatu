# 社会学習サポート（2学期期末テスト対策）

拓真の定期テスト③（2026年11月19日）社会対策アプリ。地理（アジア州・ヨーロッパ州）と歴史（飛鳥〜平安）のワーク類題72問。

公開URL: https://anbodentalclinic-pixel.github.io/shyakai-kimatu/

## 今回の変更（スプレッドシート連携）
- 解答するたびに、約3秒後に記録をGoogle Apps Script（国語アプリと同じ送信先）へ自動送信
- 送信時のアプリ名は `shakai`
- 送るシート
  - 単元まとめ：単元ごとの問題数・取り組んだ数・正解率・復習したい問題数
  - 問題ごと：72問それぞれの状態（できた／あと1回正解でできた／復習したい／まだ）、回数、最近の○×
  - 解答の記録：1回ごとの解答履歴（直近1000件）
- 問題・画面・ブラウザ内の記録は以前のまま（記録はそのまま引き継がれます）
