# 社会学習サポート（2学期期末テスト対策）

拓真の定期テスト③（2026年11月19日）社会対策アプリ。地理（アジア州・ヨーロッパ州）と歴史（飛鳥〜平安）のワーク類題72問。

公開URL: https://anbodentalclinic-pixel.github.io/shyakai-kimatu/

## 今回の変更（スプレッドシート連携）
- 解答するたびに、約3秒後に記録を専用のGoogle Apps Script（スプレッドシート「拓真 社会記録」）へ自動送信
- 送信時のアプリ名は `shakai`
- 送るシート
  - 単元まとめ：単元ごとの問題数・取り組んだ数・正解率・復習したい問題数
  - 問題ごと：72問それぞれの状態（できた／あと1回正解でできた／復習したい／まだ）、回数、最近の○×
  - 解答の記録：1回ごとの解答履歴（直近1000件）
- 問題・画面・ブラウザ内の記録は以前のまま（記録はそのまま引き継がれます）

## 更新方法
このフォルダの4ファイル（index.html・icon.png・.nojekyll・README.md）をリポジトリに上書きアップロード。

## 送信先の設定
送信先URLは設定済み（スプレッドシート「拓真 社会記録」のApps Script）。スクリプトを新しくデプロイし直してURLが変わったときは、index.html の LOG_URL を書き換える。合言葉（LOG_KEY）はスクリプト側と同じ値を設定済み。

## v14：苦手を直す
- 画面のいちばん上に「苦手を直す」を追加。まちがいの多い順に、取り組む順番を表示
- ステップ① 選んで答える（選択肢の順番を毎回入れ替え、位置で覚えるのを防ぐ）
- ステップ② 選択肢なしで書いて答える（用語・人物は入力して自動判定。説明問題はノートに書いてから答え例とキーワードで自分で丸つけ）
- まちがえたときは「あなたの答え／正解」を並べて表示し、図解と迷った理由別の直し方のコツを出す。2〜3問あとにもう一度出題
- 選ぶ・書くの両方で正解（2回続けて正解）すると「できた」
- スプレッドシートの「解答の記録」に「やり方」列、「問題ごと」に「書いて正解した回数」列を追加

## v15：あてずっぽう防止
- 問題文だけを先に表示し、「答えが浮かんだ → 選択肢を見る」を押してから選択肢を出す
- 選んだあとに自信を3段階（わかる／たぶん／勘）で答える。「勘」で正解しても「できた」に数えず復習リストに残す。「勘」でまちがえても連続正解は切れない
- 問題が出てから選ぶまでの秒数を記録。4秒未満の正解は「速すぎ」として「できた」に数えない
- まちがえたときは「次へ」が3秒押せなくなる（解説を読む時間）
- 苦手を直すのステップ①にも同じ仕組みを適用
- スプレッドシート：解答の記録に「自信」「答えるまでの秒数」、単元まとめに「勘・速すぎの回数」、問題ごとに「勘・速すぎで正解した回数」を追加

## v16：図のネタバレ防止
- 答えるまで、図解の中で答えにあたるカード（正解の言葉を含むもの）を「？？？」にし、下のまとめ文も隠す
- 自信ボタンを押して答えが確定したら、隠した部分とまとめ文を表示
- 図の流れ（途中のカード）は答える前から見えるので、「図を見ながら考える」はそのまま
